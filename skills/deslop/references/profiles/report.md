# Profile: report

Business / project reports, briefs, memos, internal docs, client-facing summaries.

**Goal:** warm-professional. Credible and polished but sounds like a person, not an institution.

- **Selective contractions** ("it's," "don't"; not "wouldn't've"). First person for
  judgement calls ("we recommend"), third person for findings.
- **Concrete over adjective.** Replace "significant improvement" with the number.
- **Kill corporate jargon** on top of the standard catalog: *leverage, synergy, stakeholder
  alignment, circle back, move the needle, best-in-class, low-hanging fruit.*
- **Structure is allowed** but not bolded-header bullet lists (patterns §C3) for everything —
  use real prose where ideas connect, lists only for genuinely parallel items. No emojis.
- **End with a direction, not a platitude.** Replace "exciting times ahead" (§E3) with the
  actual next step and owner.
- **Preserve:** real data, dates, named owners, defined scope.
